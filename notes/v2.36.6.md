**Selection Inspector v2.36.6**: first release on GitHub. The add-in is unchanged; it now comes with installers and install steps.

- **Installers.** The zip now has `install-macos.command`, `install-windows.cmd` and `install-windows.ps1`. Each replaces any older copy in Fusion's AddIns folder and leaves itself behind.

- **Documentation.** The long README moved out of the add-in folder into the repository's design notes and the documentation page.
