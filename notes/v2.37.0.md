Released: Nov 24, 2026

**Selection Inspector v2.37.0**: settings kept in a file, Reset all, update check, and an error strip.

- **Settings survive reinstalls.** Column widths, log height and copy mode are saved to a settings file outside the add-in folder instead of only in Fusion's web cache. Your current values are carried over the first time this version runs.
- **Reset all.** Now on the Tools tab. It asks first, then restores every setting and returns the palette to its opening state (List tab, log hidden, filters and toggles off, natural sort, default widths). Before, Reset only restored column widths and sort order.
- **Update check.** The palette checks GitHub when it opens and shows a green bar when a newer version is out, with **Install update**, **Download** and **What's new**. **Tools ▸ Check for updates** checks on demand; **Tools ▸ Docs** opens the documentation.
- **Error strip.** Errors now also appear in a red strip at the top of the palette, not only in the log. Click it to dismiss.
- **No fonts from the internet.** The palette no longer loads Google Fonts, so it looks the same offline; scrollbars and form controls stay dark on Windows.
- **Cleaner Stop and Run.** Stopping the add-in now detaches its button handler, so restarting it can never leave two handlers answering one click.

**Download:** SelectionInspector.zip below, or click **Install update** in the palette.
