Qty color coding

  • Suppressed
    The placement is suppressed, so its count doesn't apply.
  • Unplaced
    The component exists but is placed nowhere in the assembly.
  • Linked
    A placement of an external (linked) component.
  • Local
    A placement of a component defined in this document.
  • Multiple
    A body or sketch shared by more than one placement.
  • Single
    Exactly one placement, or an unshared body or sketch.

Colors Entity Name, Qty and Path together. Where more than one applies, the first entry in this list wins.
